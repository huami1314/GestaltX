# Dialer Themer

Ports Dialer Themer from [jailbreakdotparty/Erosion](https://github.com/jailbreakdotparty/Erosion) (GPL-3) so the Phone app keypad can be themed from GestaltX.

**Tools → Customization → Dialer Themer**

- Import a `TelephonyUI-8` / `TelephonyUI-9` / `TelephonyUI-10` theme zip
- Preview the 12 dial pad keys
- Apply keys into `com.apple.mobilephone` → `Library/Caches/TelephonyUI-10`
- Restore Original puts the stock keys back
- After applying, open Phone and toggle light/dark until the keys appear; do not force-quit Phone

The green call button cannot be themed (same limitation as Erosion).
